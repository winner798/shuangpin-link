# 图片剪贴板互传方案

状态为待审核。双拼互联 0.4.2 提供文字剪贴板互通，以下是下一版的拟议设计。

## 复制、接收和粘贴

- Windows 和安卓设置各增加「图片互传」开关。两端完成配对并启用后，在一端复制单张图片，另一端自动接收。安卓沿用系统允许输入法访问剪贴板的时机。
- 首批支持 PNG、JPEG、WebP、GIF。复制原始图片时保留原格式和可用的动画帧。Windows 应用只提供位图像素时才编码成 PNG。复制网页上的图片网址继续作为文字处理。
- Windows 可在支持图片的应用里直接粘贴，安卓可在键盘顶栏轻触缩略图，将图片插入接受该格式的输入框。目标应用只接受文字时，提示使用其他支持图片的应用。
- 键盘顶栏展示传输进度，允许取消和重试。传输中复制了更新的内容时，较早的图片不能覆盖新剪贴板。旧版本设备继续走现有文字通道。

## 隐私与服务器资源

- 图片使用现有配对身份和 HTTPS。独立派生图片发送与接收密钥，设备端加密。传输方向、图片事件、分块序号和总数参与完整性校验。接收端完成全部校验后才写入系统剪贴板。
- 首版建议单张上限 8 MiB。中继流式转发分块密文，限制同时上传数量与暂存空间，未完成、已取消或已解绑的传输及时清理。密文最多保留 10 分钟。大小上限在测试现有服务器的资源占用后确定。
- 原图可能带有拍摄位置等元数据。拟在启用图片互传时说明，提供保留原图及移除位置元数据的选项。沿用系统敏感标记、暂停互通和锁屏保护。设备私有临时文件仅向目标应用授予所需的只读权限，预览使用缩略图。

## 验收

用合成测试图片验证两端双向传输、PNG 透明度、GIF 动画、WebP 和 JPEG、Windows 截图、支持图片与纯文字的编辑器。检查断网重试、取消、超限、损坏、过期、解绑和收图时又复制新文字。测试新版与 0.4.2 混用时的文字互通，并记录最大并发下中继的内存与暂存空间。
