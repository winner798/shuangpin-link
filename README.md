# 双拼互联

双拼互联是面向 Windows 11 和 Android 10+ 的微软双拼输入法。Windows 使用小狼毫的系统输入组件和双拼互联托盘程序，Android 使用同文的系统键盘。两端使用同一套 Rime 词库与离线联想，并通过自托管服务同步纯文本剪贴板和个人词库。

## 安装与使用

1. Windows 运行 `ShuangpinLinkSetup.exe`。安装后按 `Win + 空格` 选择小狼毫。双拼互联设置从系统托盘或开始菜单打开。
2. Android 安装与手机架构匹配的 APK，启用“双拼互联”并设为默认键盘。配对入口在输入法设置的「配置」页面。
3. Windows 填入服务器 HTTPS 地址和首次启用码，点击「启用或恢复」。在 Android 的「双拼互联 · 剪贴板和词库」中扫描 Windows 显示的二维码。二维码五分钟有效，用过即失效。
4. 复制一段不含隐私的测试文字。Windows 用 `Ctrl+V` 粘贴，Android 可使用系统粘贴或键盘剪贴板。输入法后台被手机回收后，重新打开键盘可继续接收最近的一条同步内容。

剪贴板单条上限 64 KiB，服务器保留最近一条最长 24 小时。可以暂停剪贴板、关闭共享词库，或暂停学习。两端的个人词库默认约每 10 分钟检查一次，也可以立即检查。断开网络时可正常输入和联想。

配对后，Windows 托盘设置和 Android 的「双拼互联 · 剪贴板和词库」都可点「检查更新」。客户端会校验发布签名和安装包，然后提示确认安装。从没有这个按钮的首版升级时，先手动安装 0.2.0 或更新的安装包。

## 开发

- `rime/` 包含双拼和 Windows 候选栏配置。`scripts/prepare.py` 固定并准备上游源码与发行依赖。
- `android/overlay/` 包含 Android 配对、剪贴板和词库同步代码，构建时叠加到同文源码。
- `windows/` 包含托盘程序和安装程序源码。
- `server/` 包含 Ubuntu 上的 Python/SQLite 中继。`tests/` 包含协议集成测试。
- `updates/` 包含当前版本和客户端用来校验更新的公钥。
