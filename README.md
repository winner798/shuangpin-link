# 双拼互联

双拼互联面向 Windows 11 和 Android 10+，提供微软双拼和普通拼音两种中文方案，初次安装默认使用微软双拼。两端共用简体词库和离线联想，并通过自托管服务同步文字、单张图片和个人词库。

## 安装与使用

正式安装包可在 [GitHub Releases](https://github.com/winner798/shuangpin-link/releases/latest) 下载。

1. Windows 运行 `ShuangpinLinkSetup.exe`，按系统提示授权注册输入组件。安装后按 `Win + 空格` 选择「双拼互联」。打字时用 `` Ctrl + ` `` 打开方案选择。双拼互联设置从系统托盘或开始菜单打开。
2. Android 安装与手机架构匹配的 APK，从「双拼互联」应用主页启用并选择键盘。打字时使用键盘顶部的方案切换入口。
3. Windows 填入服务器 HTTPS 地址和首次启用码，点击「启用或恢复」。在安卓端的双拼互联设置中扫描 Windows 显示的二维码。二维码五分钟有效，用过即失效。
4. 两端升级到当前版本并完成配对后，复制一段测试文字，再在另一端粘贴。Android 在解锁且键盘可用时自动接收。Windows 托盘和 Android 设备互通设置均可暂停剪贴板。

两端设置可开启模糊拼音和英文自动纠错。模糊拼音在两种中文方案中都支持 `en/eng` 与 `in/ing` 双向匹配。英文模式按空格时会离线修正常见拼写错误，比如 `teh` 改成 `the`。Android 微软双拼输入 `;` 时，可以长按或上划 F。

两种中文方案都支持用词语的拼音首字母组合选词。打开「学习选词习惯」后，同一组按键下经常选中的字词会逐渐前移。连续确认的中文词会形成搭配，下次再输入前面的词，就可以直接选后面的词。输入 `@` 可选常见邮箱后缀，继续输入 `g` 可缩小到 `@gmail.com`。电脑可按 Tab 补全，手机直接点候选。手机字母键盘可长按 Z 输入 `@`。

选词上屏后，按联想词对应的数字即可选中它。例如，按 `2` 会输入第二个联想词。也可以用鼠标或手指点选。当前没有对应的联想词时，数字照常输入。继续打拼音会换成新候选，按左右箭头、空格、回车、退格、标点或使用编辑快捷键会收起联想栏并执行原操作。手打拼音时仍可按数字选词或按空格确认首选。

第一次使用或暂停学习时也有公共续词。例如「录取」可接「通知书」，「人工智能」可接「模型」，「明天下午」可接「有空吗」。开启学习后，本机还会参考最近连续确认的词，优先显示你在相同上下文里常选的搭配。公共词库随两端的 GitHub 版本更新，拼音、正文和剪贴板内容都不会作为联想查询发送到网络。

**查看剪贴板历史**

- Android 键盘空闲时，顶栏单行显示最近复制的文字，长内容以省略号收起。点预览或右侧「剪贴板」即可在键盘里查看全文、粘贴、删除或清空。打开键盘时，也能在本机找回最近一小时内仍在系统剪贴板上的合规文字。
- Windows 右键托盘图标选「剪贴板历史」，也可从设置中的「设备互通」打开。选中条目后可以复制全文供粘贴，或逐条删除。
- 两端都能在未配对时保存本机历史。每台设备独立加密保存最近七天、最多 50 条，重复内容移到前面。成功接收的对端文字也会进入本机历史。可关闭「保存本机剪贴板历史」或清空本机记录。历史列表和个人连续选词的记录只留在当前设备。

**跨设备粘贴图片**

1. 两台设备和中继都升级到 0.5.0 或更高版本，完成配对，在两端的设备互通设置开启图片互传。原有文字互传也兼容 0.4.2。
2. 在 Windows 复制一张截图或一个图片文件。安卓解锁并打开键盘后可收到缩略图，点它即可在支持该图片格式的聊天框或编辑器中插入。反方向可在安卓应用中使用「复制图片」，然后在 Windows 应用中按 `Ctrl+V`。
3. 单张上限 8 MiB，支持 PNG、JPEG、WebP 和 GIF。双方传输的编码数据保留透明度和动画帧，粘贴效果取决于目标应用。Windows 应用只提供位图时会转换为 PNG。图片网址按文字处理。

图片互传默认关闭。启用后仍会跳过系统标记为敏感的项目。默认移除拍摄位置等附加信息，保留正常显示照片所需的朝向。需要发送带原始元数据的图片时，可在发送端显式开启保留选项。图片使用设备配对密钥端到端加密，中继只暂存分块密文，最多 10 分钟。图片使用短期粘贴缓存，七天历史适用于文字。

剪贴板自动同步新的纯文字，跳过带系统隐私标记的内容。发送端加密，接收端校验配对方向、内容完整性和有效期，并丢弃重复消息。中继只存密文，单条上限 64 KiB，有效期最多 10 分钟。系统未标记的隐私文字也可能同步，复制前可暂停互通。两端的个人词库默认约每 10 分钟检查一次，也可以关闭共享或暂停学习。断开网络时可正常输入和联想。

Windows 托盘和 Android 的双拼互联设置都可点「检查更新」。两端直接从 GitHub Releases 检查和下载，校验发布签名与安装包后提示确认安装。使用 0.3.0 之前版本时，请先从 Releases 手动覆盖安装一次。

## 开发

- `rime/` 包含输入方案和 Windows 候选窗配置。`windows/Native/` 维护独立的 Windows 输入服务标识和原生界面改动。
- `android/` 包含独立的键盘和设置界面，以及配对、剪贴板和词库同步代码。构建时叠加到同文源码。
- `windows/` 包含托盘程序和安装程序源码。
- `server/` 包含 Ubuntu 上的 Python/SQLite 中继。`tests/` 包含协议集成测试。
- `updates/` 包含当前版本和客户端用来校验更新的公钥。
- [视觉规范](design/appearance.md) 记录两端的液态玻璃配色、圆角、材质与按压反馈。
- 维护手册请看 [后期调试说明](docs/后期调试说明.md)。依赖出处请看 [开源说明](THIRD_PARTY.md)。
