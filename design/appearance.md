# 双拼互联视觉规范

适用于 Android 键盘、候选栏和设置，以及 Windows 候选窗与设置。两端沿用各自适合的布局，使用同一套颜色、材质与反馈。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | `#F4F1FB` | `#11121E` |
| 主要文字 | `#201B32` | `#F6F1FF` |
| 辅助文字 | `#645C77` | `#B8B2CB` |
| 默认强调色 | `#B8A4FF` | `#B8A4FF` |
| 选中底色 | `#E7DEFF` | `#35304F` |

- 设置页以 8dp 为间距基准，左右约 20dp。大面板、列表卡片和普通按钮分别使用约 28dp、22dp 和 16dp 圆角。紧凑键盘按键使用 8–12dp 圆角，留出视觉间隙。独立图标按钮至少有 48dp 触摸区域。
- Android 竖屏四排按键区域高 264dp，整块键位都可点按。横屏采用 168dp 的紧凑布局，为输入框留出空间。空格、退格和回车比字母键宽，微软双拼所需的分号保留独立键位。
- 中文正文使用系统无衬线字形。品牌和页面标题可略宽、圆润，带静态柔光。候选字和键帽文字保持实色。选中项同时使用字号、文字、标记或形状表达状态。
- 表面由半透明底色、左上面光和单层细边构成。背景只铺低对比度柔光。候选项和键帽共享底层材质，保持笔画、标点和光标清晰。原生窗口以透明色和渐变替代表面折射。
- 控件按压约 80ms，视觉缩放约 0.94，松手柔和回弹。动画保持原触区和布局，并遵循系统减少动态效果设置。输入、加载、错误、禁用和焦点使用明确的文字或图形提示。
